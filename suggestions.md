# Moments — Complete Prompt Bank
## Cornell Campus + Ithaca + Greater Finger Lakes

> Each prompt includes: location, GPS coordinates, geofence radius, time/weather/activity context, the nudge text, and a suggested capture style.

---

## How Prompts Work

Each prompt has contextual filters that the app uses to match against the user's current situation:

- **time_context**: `morning` (6-11am), `midday` (11am-2pm), `afternoon` (2-5pm), `golden_hour` (1hr before sunset), `evening` (5-8pm), `night` (8pm+), `any`
- **weather_context**: `sunny`, `cloudy`, `rainy`, `snowy`, `foggy`, `any`
- **activity_hint**: `post_class`, `walking`, `studying`, `eating`, `exercising`, `exploring`, `commuting`, `free_time`, `any`
- **capture_style**: What kind of moment to capture — `selfie`, `scenery`, `detail_shot`, `food`, `people`, `activity`, `candid`, `creative`
- **day_context**: `weekday`, `weekend`, `friday`, `any`

## PROMPT SELECTION ALGORITHM (Pseudocode)

```
function selectPrompt(userContext):
    candidates = []

    // 1. Location match (highest priority)
    for prompt in allPrompts:
        if distance(user.location, prompt.location) < prompt.radius:
            candidates.append(prompt)

    // 2. Filter by context
    filtered = candidates.filter(p =>
        p.time_context == currentTimeOfDay() OR p.time_context == "any"
        AND p.weather_context == currentWeather() OR p.weather_context == "any"
        AND p.day_context == currentDayType() OR p.day_context == "any"
    )

    // 3. If calendar gives activity hints
    if user.justFinishedEvent:
        boost prompts where activity_hint == "post_class"
    if user.nextEventIn > 30min:
        boost prompts where activity_hint == "free_time" or "exploring"

    // 4. Dedup — don't show same prompt twice in a week
    filtered = filtered.filter(p => !shownRecently(p, 7days))

    // 5. Fallback to time-based if no location matches
    if filtered.isEmpty():
        filtered = timeBasedFallbacks.filter(timeMatch)

    // 6. Pick one (weighted random, prefer higher-engagement prompts over time via RLHF)
    return weightedRandom(filtered)
```
